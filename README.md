    # Traffic Sign Recognition

    A Python command-line application for classifying traffic-sign images with a trained TensorFlow/Keras model.

    ## Requirements

    - Python 3.10 or 3.11
    - A trained Keras model saved at `models/traffic_sign_model.keras`
    - The model must accept RGB images resized to 32 × 32 pixels and return class scores.

    ## Installation
```bash
pip install -r requirements.txt
